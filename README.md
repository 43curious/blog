# Jon Castro

I'm Jon Castro, an audiovisual university lecturer and tech enthusiast. I teach during the day and code at night, looking for simple ways to solve complex problems.

This website is where I collect what I learn along the way: notes on creative workflows, references I want to return to, and tools and experiments I build.

You'll find three main areas:

- **Notes:** articles and guides about audiovisual work, creative tools, and things that interest me.
- **Resources:** a collection of useful tools and references for sound, film, typography, color, design, and motion.
- **Projects:** tools and experiments such as TaldeBOT, WaveSearch, Iko-Connect, and tresna.

The site is written in Spanish, for students, audiovisual creatives, and anyone curious about the overlap between teaching, design, and technology.
