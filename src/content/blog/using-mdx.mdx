This theme comes with the [@astrojs/mdx](https://docs.astro.build/en/guides/integrations-guide/mdx/) integration installed and configured in your `astro.config.mjs` config file. If you prefer not to use MDX, you can disable support by removing the integration from your config file.

## Why MDX?

MDX is a special flavor of Markdown that supports embedded JavaScript & JSX syntax. This unlocks the ability to [mix JavaScript and UI Components into your Markdown content](https://docs.astro.build/en/guides/integrations-guide/mdx/#mdx-in-astro) for things like interactive charts or alerts.

If you have existing content authored in MDX, this integration will hopefully make migrating to Astro a breeze.

## Example

Here is how you import and use a UI component inside of MDX.  
When you open this page in the browser, you should see the clickable button below.

import HeaderLink from '../../components/HeaderLink.astro';
import Chart from '../../components/Chart.astro';

<HeaderLink href="#" onclick="alert('clicked!')">
	Embedded component in MDX
</HeaderLink>

## Líneas: datos medidos

A line chart accepts numeric `{ x, y }` values. Hover a line or its legend item to isolate it.

export const weeklyViews = [
	{ label: 'Vídeos largos', color: '#4137ff', values: [{ x: 1, y: 240 }, { x: 2, y: 310 }, { x: 3, y: 280 }, { x: 4, y: 420 }, { x: 5, y: 510 }, { x: 6, y: 480 }] },
	{ label: 'Clips', color: '#e03131', values: [{ x: 1, y: 180 }, { x: 2, y: 220 }, { x: 3, y: 260 }, { x: 4, y: 250 }, { x: 5, y: 330 }, { x: 6, y: 390 }] },
];

<Chart
	mode="line"
	title="Visualizaciones semanales"
	xLabel="Semana"
	yLabel="Visualizaciones"
	showTooltip
	animateOnScroll
	series={weeklyViews}
/>

## Líneas: sin puntos ni cuadrícula

Use `showPoints={false}` and `showGrid={false}` for a quieter chart.

	{ label: 'CPU', color: '#d9480f', values: [{ x: 1, y: 68 }, { x: 2, y: 61 }, { x: 3, y: 57 }, { x: 4, y: 49 }, { x: 5, y: 45 }] },
];

<Chart
	mode="line"
	title="Tiempo de renderizado optimizado"
	xLabel="Versión"
	yLabel="Segundos"
	showPoints={false}
	showGrid={false}
	series={renderTimes}
/>

## Líneas: toggle de dos estados

A line chart can optionally cycle between two states with one toggle.

export const toggleLines = [
	{ label: 'Alta', state: 0, color: '#4137ff', values: [{ x: 1, y: 90 }, { x: 2, y: 84 }, { x: 3, y: 76 }, { x: 4, y: 68 }] },
	{ label: 'Baja', state: 1, color: '#008f5a', values: [{ x: 1, y: 144 }, { x: 2, y: 132 }, { x: 3, y: 124 }, { x: 4, y: 116 }] },
];

<Chart
	mode="line"
	title="Calidad de imagen"
	xLabel="Escena"
	yLabel="AVG FPS"
	toggle={{ labels: ['Alta', 'Baja'] }}
	series={toggleLines}
/>

## Curvas: funciones

A curve chart samples a JavaScript function across `xDomain`, which is useful for benchmarks and projections.

export const benchmarks = [
	{ label: 'Proceso A', color: '#4137ff', fn: (x) => 12 + x * 1.8 + x * x * 0.12 },
	{ label: 'Proceso B', color: '#e03131', fn: (x) => 18 + x * 1.1 + x * x * 0.2 },
];

<Chart
	mode="curve"
	title="Tiempo de renderizado"
	xLabel="Complejidad"
	yLabel="Segundos"
	xDomain={[0, 10]}
	series={benchmarks}
/>

## Curvas: funciones matemáticas

Functions can also describe waves, thresholds, or other models.

export const signalModels = [
	{ label: 'Onda', color: '#0077ff', fn: (x) => Math.sin(x) * 8 },
	{ label: 'Límite', color: '#7048e8', fn: (x) => 4 + Math.cos(x * 0.7) * 2 },
];

<Chart
	mode="curve"
	title="Modelos de señal"
	xLabel="Tiempo"
	yLabel="Amplitud"
	xDomain={[0, 12]}
	yDomain={[-10, 10]}
	series={signalModels}
/>

## Barras: comparar categorías

Use `bar` for grouped vertical bars. Each point's `x` value becomes a category label.

export const projectCosts = [
	{ label: 'Producción', color: '#4137ff', values: [{ x: 'Equipo', y: 1200 }, { x: 'Rodaje', y: 2400 }, { x: 'Post', y: 1800 }] },
	{ label: 'Estimación', color: '#d9480f', values: [{ x: 'Equipo', y: 1500 }, { x: 'Rodaje', y: 2100 }, { x: 'Post', y: 2200 }] },
];

<Chart
	mode="bar"
	title="Coste del proyecto"
	xLabel="Partida"
	yLabel="Euros"
	yDomain={[0, 3000]}
	series={projectCosts}
/>

## Torre: una serie de costes

`tower` is a compact alias for a single-series vertical cost graph.

export const monthlyCosts = [
	{ label: 'Coste', color: '#e03131', values: [{ x: 'Ene', y: 320 }, { x: 'Feb', y: 460 }, { x: 'Mar', y: 390 }, { x: 'Abr', y: 580 }, { x: 'May', y: 510 }] },
];

<Chart
	mode="tower"
	title="Coste mensual"
	xLabel="Mes"
	yLabel="Euros"
	yDomain={[0, 700]}
	series={monthlyCosts}
/>
